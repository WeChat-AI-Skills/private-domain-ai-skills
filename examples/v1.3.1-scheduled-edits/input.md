# 已排期任务修改：合成场景输入

本目录记录 v1.3.1 的三个场景组。所有账号、人员、任务、素材均为虚构；2030 年时间只用于模拟“尚未执行”的未来排期，不是实际生产安排。

| 组 | 输入 | 实际逐轮答复 |
| --- | --- | --- |
| G1：只换一张图 | [输入](group-1.raw.json) | [可读轨迹](G1.md) · [JSON](G1.json) |
| G2：无修改入口、保存超时和回读不一致 | [输入](group-2.raw.json) | [可读轨迹](G2.md) · [JSON](G2.json) |

每组由一个新上下文 Agent 读取该组初始输入与隔离安装后的技能。先保存当轮答复，再注入下一轮观察；作答者不读取评分标准、其他组答案和未来观察。G2 主路径采用保存超时；显式失败是独立反事实分支，不与主路径混记。G3 先停在负责人决定前，再逐轮检查明确授权、取消待核、执行状态未知与最终取消确认。

这是模拟界面观察下的动作选择检查，未点击真实页面，也未发送负责人消息或操作客户任务。输入夹具中的观察由演练提供，不是工具执行回执。完整行为已保存，JSON 仅移除内部审查调用标识，业务答复原文不改写。
