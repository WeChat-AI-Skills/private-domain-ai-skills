# S08 场景答复

不能写成“安装后就能使用 PPT 里的全部功能”。目前能说的是：这个安装包提供了基础操作方法和本地检查工具；客户环境是否能执行、各项功能是否可用，还要逐项现场验收。

**当前已有证据与缺口**

- 根据题目提供的记录，v1.3.0 含 16 项技能，安装测试和合成测试通过；本次没有重新运行测试。这些结果不证明客户现场已经可用。
- 安装包提供上岗与会话检查、图文朋友圈、指定好友任务消息、本地绑定及回执校验。安装副本还给出原任务查询与结果核对方法，但现场状态仍是 `not_verified`，没有已验证的客户部署版本清单。
- 客户宿主工具配置尚未观察；安装技能不会开通 SCRM 账号、取得登录态、安装控制服务或自动启动后台任务。客户有浏览器也不等于 Codex 当前会话能控制其已登录 SCRM。
- PPT 所列“视频、链接、视频号”须按媒体类型和客户当前版本另验；“聚合聊天即时回复”尚未完成适配。“自动通过好友、自动标签、自动回访、自动加粉、风控留存”也没有本题证据支持其已由本包适配并通过客户现场验收，不能写成安装即有或默认开启。PPT 的产品功能说明与本包已验证的交付范围需要分别标注。
- 本题没有提供官方 API 文档，不能据此承诺官方 API 接入或全部功能覆盖；同样不能反推厂商没有 API。本包当前采用宿主界面操作方法，本地校验脚本不能证明真实授权、发送或发布成功。

**可给客户使用的文案草稿**

> v1.3.0 安装包包含 16 项私域运营技能，提供 SCRM 上岗检查、图文朋友圈排期、指定好友任务消息及原任务结果核对的操作指引，并附本地绑定与回执校验工具。安装与合成场景测试已通过；客户现场适配尚需验收。使用前需具备可用的 SCRM 账号、相应权限及 Codex 可操作的浏览器或桌面工具，并完成会话连接和指定任务验证。PPT 中其他媒体类型、聚合聊天及自动化等功能，按客户系统实际支持情况与单项验收结果确认。

这段是本次拟定的客户说明，尚未对外发送，也没有修改 PPT 或其他对外材料。

**下一步拟执行**

1. 将客户说明与 PPT 功能清单逐项对照，区分“包内已有操作路径”“需客户现场验证”“尚未适配或缺少证据”。先移除“装完全部可用”的承诺，不把产品宣传范围等同于本包交付范围。
2. 客户启动部署后，先发现其宿主真实可用工具，在指定正式入口只读核对当前会话、租户、角色、授权工作号、时区、相关页面和原任务结果入口。缺工具或权限时列出具体缺口；需要登录时由客户在正式界面完成。
3. 在获得明确测试范围后，使用客户指定的测试工作号、测试对象与素材，优先验证图文朋友圈和指定好友任务消息。固定最终内容、时间与作用范围，提交后回读原任务，再分别核对发布或出站结果；“排期已保存”“实际发布/发送”“客户可见或已读”分别记录，缺失证据保留未核实。
4. 对其余 PPT 功能单独确认官方资料、实际页面、工具能力和授权，再决定是否开展专项适配与验收；不以试发、试加好友或开启长期自动化来完成只读检查，也不承诺 Codex 关闭后持续运行或自动回读。

以上均为后续计划。本次仅读取所指定的场景和技能资料、生成说明文案；没有连接真实 SCRM、发送消息、变更业务配置或执行现场测试。
