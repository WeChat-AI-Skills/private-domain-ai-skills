# 标签体系

标签的作用是**让筛选和判断可复用**，不是给客户贴满贴纸。
一个标签只有在"会改变下一步动作"时才值得存在。

## 1. 九个维度

| 维度 | 取值示例 | 改变什么 |
| --- | --- | --- |
| 来源 | 直播、小红书、转介绍、线下、老客 | 渠道复盘、欢迎话术 |
| 品类 | 裤装、护肤、咖啡、咨询 | 推荐范围 |
| 需求 | 通勤、送礼、活动、复购 | 内容与话术 |
| 偏好 | 宽松腰、纯棉、低糖、安静 | 推荐精度 |
| 价格带 | <300、300-500、500-1000、>1000 | 避免超预算 |
| 阶段 | 新客、意向、已购、复购、沉睡、不打扰 | 跟进节奏 |
| 行为 | 夜间咨询、问过尺码、看过朋友圈、加购未付 | 时机判断 |
| 风险 | 投诉史、价格敏感、易怒、退换多 | 授权与话术 |
| 权益 | 会员、老客价、团体单 | 报价范围 |

## 2. 命名规则

```text
维度:值        ✅  品类:裤装    ✅  行为:加购未付
品类-裤子      ❌  维度不统一，无法聚合
裤子           ❌  没有维度，筛选会混
高意向客户     ❌  这是分层，不是标签
```

- 中文值，冒号用半角 `:`；
- 不用空格、不用下划线混排；
- 一义一词：不要同时存在"宽松腰""腰部宽松""不勒腰"；
- 同一维度最多 3 个值，超过说明维度太粗或标签太细。

## 3. 好标签与坏标签

| 标签 | 判断 | 原因 |
| --- | --- | --- |
| `需求:送礼` | 好 | 直接改变推荐与包装 |
| `行为:问过尺码` | 好 | 改变跟进时机 |
| `风险:价格敏感` | 好 | 改变报价方式 |
| `客户很好说话` | 坏 | 不可验证、不改变动作 |
| `潜在高价值` | 坏 | 没有定义，无法筛选 |
| `女性` | 坏 | 与动作无关，且涉及不必要的个人信息 |

## 4. 标签与阶段的关系

阶段是"结果"，标签是"依据"。不要用标签替代阶段判断：

```text
标签：行为:问过尺码 + 行为:问库存 + 需求:周末活动
→ 阶段：高意向（近 7 天，有明确购买信号）
→ 动作：24 小时内给方案
```

反过来，只有 `来源:直播` 一个标签，不能推出"高意向"。

## 5. 冲突处理

| 冲突 | 处理 |
| --- | --- |
| `需求:送礼` 与 `需求:自用` | 以最近一次原话为准，另一个进备注 |
| `价格带:<300` 与推荐 800 元商品 | 先确认预算是否变化，不擅自提价 |
| `阶段:已购` 与 `风险:投诉史` | 阶段照常，触达降为 B 级人工确认 |
| `阶段:不打扰` 与任何营销标签 | 不打扰优先，任何活动都不发 |

## 6. 治理

- **新增**：先写定义、取值、对应动作，进项目配置；试用 2 周再全员用；
- **废弃**：保留历史数据，停止新打；90 天后归档；
- **审计**：每月抽查 20 个档案，看标签是否有依据；
- **指标**：标签使用率、冲突率、无依据率。冲突率高说明定义不清，不是执行不力。
