# 回复模式

每条回复都要回答客户一个隐含问题：**"你听懂我了吗？"**
先让他确认听懂了，再谈方案。

## 1. 开场：接住场景

| 客户说 | 不要回 | 可以回 |
| --- | --- | --- |
| "在吗" | "在的，请问有什么可以帮您" | "在的，您说～" |
| "这个有货吗" | "有的呢亲" | "有的，黑色 M 还有 3 件。您平时穿 M 吗？" |
| "随便看看" | "好的，有需要叫我" | "这两天问得多的是通勤直筒，您平时穿裤子最怕勒腰还是怕显胯？" |
| "太贵了" | "已经是最低价了" | "理解，这款贵在面料和腰头。您预算大概多少？我看看有没有同版型的。" |

## 2. 追问：一次一个

```text
"收到～您说的是周末活动穿对吗？我按这个给您挑。"
"方便说下身高体重吗？我帮您定码，省得来回换。"
"您收货城市是哪里？我核对下周六前能不能到。"
```

追问后停住，等客户答。不要自问自答，也不要追加第三个问题。

## 3. 推荐：给 2–3 个，说清差异

```text
"按您的需求我挑 3 条：
① 直筒 299：最稳，通勤能穿；
② 微阔 359：腰头更宽，坐着不勒；
③ 加绒 399：怕冷选这条，但会厚一点。
您更在意不勒腰，我倾向 ②。"
```

要点：数量不超过 3；每条一句差异；最后给一个倾向，不把选择完全丢回去。

## 4. 报价：先确认再报价

```text
"这款日常 399，这周活动 359，活动到周日。
您要的话我先帮您留一件，尺码确认后下单？"
```

- 不主动给未授权的折扣；
- 不写"全网最低"；
- 价格含不含运费、能不能退换，一次说清。

## 5. 异议：先接住，再拆

| 异议 | 结构 | 示例 |
| --- | --- | --- |
| 贵 | 认可 → 拆价值 → 给选择 | "理解，确实不算便宜。它贵在…如果您预算在 300 内，我有一条同版型的。" |
| 再想想 | 尊重 → 留由头 | "好的，不着急。周四到新款，到时候我发您一张图？" |
| 别家更便宜 | 不贬低 → 确认同款 → 讲差异 | "如果是同面料同版型，那确实划算。方便发我链接吗？我帮您看差在哪。" |
| 怕不合适 | 给保障 | "支持 7 天退换，尺码不对我帮您换，运费我们承担。" |

## 6. 收尾：给下一步，不逼单

```text
"那我先按 M 给您留到明天中午，您考虑好跟我说一声就行。"
"链接发您，拍下后我盯发货。"
```

避免："今天不定就没这个价了""最后一件"（除非属实且有依据）。

## 7. 客户不回

- 24 小时内：不追；
- 48 小时后：换由头追一次（新品、补货、活动），不重复原话；
- 连续 2 次无回应：暂停，转培育池；
- 客户回"不用了"：立刻停止，记录原因。

## 8. 深夜与清晨

```text
深夜："收到，我先帮您记下。明天上午核对库存后回复您，您先休息。"
清晨："昨晚您问的直筒裤，M 码有货，周六前能到。需要我帮您留吗？"
```

深夜不承诺、不催单；清晨只回昨夜未答的那件事。

## 9. 语气校准

| 店铺类型 | 语气 | 称呼 |
| --- | --- | --- |
| 女装 / 生活方式 | 轻松、短句、有画面 | "您" |
| 高客单 / 定制 | 稳、少表情、专业 | "您" |
| 食品 / 生鲜 | 热情、口语 | "您" / "宝"（按店铺习惯） |
| 2B / 咨询 | 直接、结论先行 | "您" |

没有店铺口吻示例时，一律用中性、简洁的"您"。

## 10. 一条回复的自检

- [ ] 有没有复述客户的关键信息？
- [ ] 有没有给具体选项，而不是"很多"？
- [ ] 问号是否 ≤ 2 个？
- [ ] 有没有未确认的承诺？
- [ ] 客户读完知道下一步做什么吗？
