# 追问库

追问的原则：**问一个能改变下一步的问题。** 不是把表单填满。

## 1. 通用四问（按优先级）

1. "您收货城市是哪里？我核对下时效。"（决定能不能承诺）
2. "平时穿什么码？身高体重方便说吗？"（决定推荐）
3. "主要什么场合穿/用？"（决定风格）
4. "是自己用还是送人？"（决定包装与推荐）

## 2. 按品类

### 服饰

| 目的 | 问法 |
| --- | --- |
| 尺码 | "平时穿 M 还是 L？身高体重方便说下吗？" |
| 版型 | "您更怕勒腰还是怕显胯？" |
| 场合 | "通勤穿还是周末穿？" |
| 材质 | "容易出汗吗？介意羊毛扎肤吗？" |

不要问"您喜欢什么风格"——太开放，客户答不上来。给两个对立选项让他选。

### 美妆 / 护肤

| 目的 | 问法 |
| --- | --- |
| 肤质 | "偏干还是偏油？最近有没有泛红？" |
| 诉求 | "最想先解决哪一个：干、暗、还是痘？" |
| 敏感 | "以前用酸类会不会刺痛？" |
| 使用场景 | "每天化妆还是不化妆？" |

涉及功效、治疗、药妆时，只描述成分与使用感，不做疗效承诺。

### 食品 / 生鲜

| 目的 | 问法 |
| --- | --- |
| 口味 | "偏甜还是偏酸？能吃辣吗？" |
| 人数 | "几个人吃？我按份量给。" |
| 时效 | "哪天要用？冷链一般 2 天。" |
| 忌口 | "有过敏或忌口吗？" |

### 家居 / 大件

| 目的 | 问法 |
| --- | --- |
| 尺寸 | "放的位置多宽？我帮您看会不会顶到。" |
| 安装 | "需要上门安装吗？" |
| 楼层 | "有电梯吗？" |
| 风格 | "家里偏原木还是偏白？" |

### 2B / 咨询

| 目的 | 问法 |
| --- | --- |
| 业务 | "现在主要靠什么获客？" |
| 规模 | "团队几个人在跟客户？" |
| 痛点 | "最想先解决接不住还是跟不上？" |
| 决策 | "这件事您自己定，还是要和合伙人商量？" |

## 3. 按场景

| 场景 | 追问 | 不要问 |
| --- | --- | --- |
| 送礼 | 送给谁、什么关系、预算、要不要包装 | "您想送什么"（客户就是不知道才来问） |
| 活动 | 哪天、什么场合、要不要拍照 | "您喜欢什么"（太泛） |
| 复购 | 上次那件穿着怎么样、要不要同款不同色 | "还要买吗"（太直白） |
| 售后 | 订单号、问题照片、期望处理方式 | "为什么不喜欢"（容易激化） |
| 比价 | 对比的是哪款、看重什么 | "是不是嫌贵"（预设敌意） |

## 4. 什么时候不问

- 客户已经给了答案，不要复问；
- 客户在投诉，先处理情绪与事实，不要做需求调研；
- 客户明确说"就看看"，只给一个锚点，不追问；
- 深夜，只问影响当下回复的那一个，其余留到白天；
- 已经问过两次没答，换方式或先给方案，不要第三次追问。

## 5. 问法的三个禁忌

1. **连环问**：一条消息里 3 个以上问号；
2. **封闭到无意义**："您是要买裤子吗？"
3. **把选择题做成填空题**："您想要什么样的？"

好问法 = 两个具体选项 + 一个理由：

> "您是要通勤穿还是周末穿？通勤我推荐直筒，周末可以看宽松卫裤。"
