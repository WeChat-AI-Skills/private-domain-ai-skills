# 一对一接待与需求识别

接待的目标不是"回得快"，是**在一条消息里听出客户没说出口的那部分**，然后用一个问题把它补上。

## 何时使用

- 客户发来咨询，需要判断需求并回复；
- 客户只说了一句话，信息不全，不知道该推荐什么；
- 客户问尺码、库存、发货、优惠，需要确认后再答；
- 客户说"随便看看""再看看"，需要决定跟还是放；
- 客户比价、压价，需要判断是否转人工。

## 输入

至少要有一句客户原话。有这些更好：历史对话、订单、商品表、店铺口吻示例、当前活动。

缺商品表时，不要编造 SKU、价格、库存；只给"推荐方向 + 需要确认的候选"。

## 第一步：只读原话，先不下结论

把客户的话逐句拆开，标出三类信息：

| 类型 | 例子 | 处理 |
| --- | --- | --- |
| 明说 | "预算 500""周末活动""腰部宽松" | 直接进档案 |
| 暗示 | "最近胖了""上次那条有点勒" | 标为推断，附依据 |
| 没说 | 收货城市、身高体重、颜色偏好 | 进"待确认"，选一个问 |

**不要从"客户问裤子"直接跳到"推荐裤子"。** 先问：他为什么现在买？买给谁？什么时候要用？

## 第二步：拆需求四要素

| 要素 | 要拿到什么 | 缺失时的影响 |
| --- | --- | --- |
| 场合 | 通勤、约会、婚礼、运动、日常 | 决定版型与风格 |
| 预算 | 数字或区间 | 决定推荐带 |
| 偏好 | 版型、材质、颜色、避讳 | 决定候选范围 |
| 品类 | 具体品类与数量 | 决定选品 |

再加三个"成交前必须确认"的字段：

- **收货城市 / 时效**：决定能不能承诺"周六前到"；
- **尺码依据**：身高体重、平时穿的码、或具体围度；
- **使用人**：自己穿、送人、还是给孩子/长辈。

### 只问一个问题的取舍

一次最多问两个，优先顺序：

1. 会改变推荐结果的（尺码、使用场景）；
2. 会改变承诺的（收货城市、时效）；
3. 会改变价格的（数量、会员、活动）；
4. 锦上添花的（颜色、包装）。

已经给了的信息不要重复问。客户刚说完预算，再问"您预算多少"会立刻掉信任。

## 第三步：判断阶段与信号

| 信号 | 表现 | 阶段 | 动作 |
| --- | --- | --- | --- |
| 强 | 问尺码、库存、发货、怎么买、能不能便宜 | 高意向 | 直接给方案 + 推进 |
| 中 | 问材质、对比、看评价、回复变长 | 意向 | 给证据 + 一个追问 |
| 弱 | "随便看看""先收藏"、回复很短 | 培育 | 给一个锚点，不逼单 |
| 负 | 嫌贵、说再看看、明确拒绝、抱怨 | 暂停 | 停止推进，记录原因 |

强信号不要拖：客户问"有货吗"，先答有/没有，再问别的。
弱信号不要追：给一个具体的"下次由头"（新品、活动、补货），然后放手。

## 第四步：写回复

一条好回复的结构：

```text
接住场景（复述客户说的关键信息）
→ 给 2–3 个具体选项（不是"有很多款"）
→ 问一个最关键的问题
→ 留一个不逼单的出口
```

示例：

> 收到～周末活动穿、腰部宽松、500 内，我先帮您挑 3 条。
> 您收货城市是哪里？我核对下周六前能不能送到。

要点：

- **短句**，像人说话，不像客服模板；
- **复述**客户的关键词，让他确认"你听懂了"；
- **具体**：说"3 条""腰部宽松"，不说"很多新款"；
- **不承诺**没确认的库存、时效、价格；
- **不逼单**：不用"最后一件""再不买没了"。

店铺口吻以用户提供的示例为准；没有示例时，用中性、简洁、有礼貌的表达，不用"亲"。

## 第五步：风险与转人工

出现以下情况，停止推荐，转人工（C 级）：

- 投诉、退款、纠纷；
- 定制、改码、非标规格；
- 要求超授权折扣、账期、返点；
- 医疗功效、金融收益、法律结论；
- 客户明确要求人工，或明显不满。

在等接手时，只发不承诺结果的过渡句。

## 输出格式

```markdown
【客户】A（来源：直播 / 老客 / 转介绍）
【已知】场合：… · 预算：… · 偏好：… · 品类：… · 城市：…
【推断】…（依据：客户原话"…"）
【待确认】…（为什么问：…）
【阶段】高意向 / 意向 / 培育 / 暂停
【建议回复】
> …
【动作】追问 → 核对库存 → 推荐 → 建档
【风险】…
【授权】A（仅草稿）/ B（需确认发送）
```

结论在前，依据在后。没有依据的判断，标"推断"，不要写成事实。

## 常见场景

### 深夜咨询

客户 23:48 发消息。可以回复（客户在等），但：

- 不主动追加第二条；
- 不做需要同事配合的承诺（"明天问下仓库"要说清什么时候回）；
- 次日早会进"晨报"：昨夜接待了谁、谁还有待确认、谁转了人工。

### "随便看看"

不追问"想看点什么"（等于把问题丢回去）。给一个具体锚点：

> 这两天问得最多的是通勤直筒和加绒款，您平时穿裤子更怕勒腰还是怕显腿粗？我按这个给您挑。

然后停。客户不回，不追。

### 比价 / 压价

- 不贬低竞品，不说"他家质量差"；
- 不立刻让价，先确认是不是同款、同材质、同售后；
- 价格让步属于 B 级，必须负责人确认；
- 话术方向：讲清差异（面料、版型、售后），给替代方案（套餐、赠品、老客权益），不硬扛。

## 不要做

- 不要一次问五个问题；
- 不要编造库存、发货时间、优惠力度；
- 不要用"亲亲""宝贝"这类与店铺口吻不符的称呼；
- 不要把"客户没回"当成"客户没兴趣"，也不要当成"可以继续追"；
- 不要在投诉场景里继续推销。
