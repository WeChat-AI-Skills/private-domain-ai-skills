# 群议程与邀约话术

## 1. 活动前 1 天：公告

```text
【周六试穿答疑】
时间：11-15（周六）14:00–17:30
地点/方式：店里 / 群内图文直播
今天能解决：尺码怎么选、不同身高上身对比、搭配
需要准备：平时穿的裤子一条（方便对比）
不来的也能看记录，结束后我发群里。
```

五行为限。不写"惊喜福利""神秘大奖"，除非确有其事。

## 2. 邀约（一对一，不是群发）

### A 层：问过尺码

```text
"您上次问的宽松版型，周六 14:00 群里有真人试穿对比，
155 和 170 各一个，能看到实际效果。
想来我拉您进群？"
```

### B 层：买过同品类

```text
"您买过的那条直筒，这次到了同版型的新色。
周六群里先看，老客可以留货。要进群吗？"
```

### C 层：高意向未下单

```text
"您上次看的那款，周六现场可以试，尺码问题当场解决。
不方便来的话，我也可以帮您视频比一下。进群吗？"
```

### 同意后的确认

```text
"好，我拉您进群。周六 14:00 开始，来不了也能看记录。"
```

### 未回复（活动前一天，仅一次）

```text
"明天 14:00 开始，先把议程发您，来不了也不用回。"
```

## 3. 开场（14:00）

```text
"开始啦。今天三件事：
① 三个身高试同一条裤子；
② 尺码怎么选，现场问；
③ 15:30 说老客权益。
问题随时发，我一个个回。"
```

## 4. 中段

- 每 20–30 分钟一个信息块，不连续刷图；
- 每个问题 @ 提问人回复，不让问题沉底；
- 价格问题统一话术："价格我单独发您，群里不刷屏。"
- 有人质疑，先承认感受，再给事实，不争输赢。

## 5. 限时权益（15:30）

只说确认过的：

```text
"老客价到今晚 22:00，需要的私信我留货，不用在群里报码。"
```

不写"最后 3 件"（除非属实）、不写"过时不候"。

## 6. 收尾（17:30）

```text
"今天的问题我整理了一份，稍后发群里。
没答完的私信我。下次活动提前一天在这里说。"
```

## 7. 沉默群怎么救

| 现象 | 原因 | 动作 |
| --- | --- | --- |
| 只有人进，没人说话 | 开场没给"现在做什么" | 直接抛一个具体问题："165 穿 M 还是 L，有人想先看吗？" |
| 问了没人回 | 问题太难/太开放 | 改成二选一："要短款还是长款？" |
| 只有一个人说话 | 其他人怕打扰 | 点名邀请："@小 A 您上次问的码，正好今天能试。" |
| 开始发广告 | 缺规则 | 公告补一条"只聊今天的尺码与搭配"。 |

## 8. 角色分工

| 角色 | 做什么 |
| --- | --- |
| 主讲 | 按议程交付，控节奏 |
| 答疑 | 盯问题，逐个回，答不了转一对一 |
| 记录 | 记问题、成交、待办 |
| 负责人 | 权益确认、例外裁决、投诉处理 |

两个人也能办：一个讲，一个回。一个人办，就减少互动环节。

## 9. 事故处理

| 事故 | 处理 |
| --- | --- |
| 价格说错 | 立即更正，说明以确认版为准，不狡辩 |
| 有人发广告/攻击 | 私信沟通，必要时移出，群内不吵架 |
| 承诺了做不到的 | 当场说明，给替代方案，转人工 |
| 群二维码外泄 | 关闭入群，逐个确认 |

## 10. 活动后 24 小时

- 发记录与答疑问答；
- 逐人核对状态（同意未进群/进群未下单/到场未成交）；
- 列明日待办；
- 把有效话术与失效环节写进复盘。
