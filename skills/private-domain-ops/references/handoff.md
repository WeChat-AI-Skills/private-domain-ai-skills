# 交接卡与转人工

## 1. 什么时候必须转

出现以下任一情况，停止自动化，出交接卡：

- 投诉、退款、纠纷、平台处罚、监管或媒体相关；
- 定制、改码、非标规格、特殊报价；
- 超出授权范围的折扣、账期、返点、赠品；
- 医疗功效、金融收益、法律结论等敏感表述；
- 客户明确要求人工，或表达强烈不满；
- 连续两轮未解决；
- 事实无法确认，但客户在等答复。

## 2. 交接卡模板

```markdown
【转人工】客户 A（微信昵称：小 A）
【级别】C
【原因】客户要求改裤长，超出标准改码范围
【客户原话】"我 165，裤长能改到 95 吗？"
【已确认】尺码 M、颜色黑、收货杭州、预算 500、周六要用
【已做过】说明标准裤长 100；改短需定制，工期 5–7 天
【待决定】是否接定制、加价多少、能否加急
【风险】客户周六要用，按标准工期来不及，先别答应
【建议】给两个选项：换九分款现货 / 加急定制（需确认费用）
【交接人】店长 王，今日 18:00 前
【留痕】对话截图 3 张，已存客户档案
```

## 3. 交接的三条规矩

1. **交上下文，不交结论。** 把原话、已确认事实、已做过的动作一起给，接手的人不用重新问一遍客户。
2. **不替接手人承诺。** 交接卡里写"建议"，不写"已答应"。
3. **有回执。** 记录谁接了、什么时候接的、结果如何；没回执的交接视为未完成。

## 4. 过渡话术（可用）

在等人接手的空档，只能发不承诺结果的话：

- "收到，这个问题我需要和店长确认一下，今天 18:00 前回复您。"
- "您的需求我记下了，稍后由专人跟您对接，不用重复说明。"

不能发：

- "肯定可以改" / "给您免单" / "我保证今天处理好"。

## 5. 交接之后

- 把交接原因写进客户档案的"风险"字段；
- 如果同类交接一周出现 3 次以上，交给 `sales-review` 看是否需要补规则或补授权；
- 复盘时区分"人的问题"与"规则的问题"：是没人接，还是规则没覆盖。
