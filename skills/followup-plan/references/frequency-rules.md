# 频率、时间窗与停止规则

## 1. 默认频控

| 项目 | 默认值 | 计算方式 |
| --- | --- | --- |
| 一对一主动触达 | ≤ 2 次/周/人 | 滚动 7 天，含跟进与活动邀约 |
| 最小间隔 | 48 小时 | 上次主动消息到本次 |
| 群发/朋友圈 @ | ≤ 1 次/周/人 | 单独计数，不与一对一合并 |
| 连续无回应 | 2 次暂停 | 暂停 7 天后再评估 |
| 免打扰时段 | 22:00–08:00 | 只回复，不主动发 |

客户主动发消息不占用主动触达额度，但**回复不等于获得新的营销许可**。

## 2. 时间窗

| 客群 | 建议时段 | 理由 |
| --- | --- | --- |
| 上班族 | 12:00–13:00，19:30–21:30 | 通勤与午休 |
| 宝妈 | 10:00–11:30，14:00–16:00 | 孩子上学/午睡 |
| 店主/2B | 09:30–11:30，14:00–17:00 | 工作时间 |
| 夜间活跃客群 | 20:00–23:00 | 需单独配置，不默认 |

时段是起点，不是真理。用真实回复率校准，按客群分别配置。

## 3. 计数规则

- 以"客户"为单位，不以"渠道"为单位：微信 + 群 + 朋友圈合并看；
- 同一天发两条不同内容，算 2 次；
- 系统自动回复（如"已收到"）不计入，但不能用来绕过频控；
- 活动邀约计入主动触达；
- 客户未读不算送达失败，仍计入次数。

## 4. 停止信号

| 信号 | 动作 |
| --- | --- |
| "不需要""别发了""退订" | 立即停止，标记不打扰 |
| 连续 2 次无回应 | 暂停 7 天，之后最多再试 1 次 |
| 投诉/退款 | 停止营销，转人工 |
| 拉黑/删除 | 不再尝试添加 |
| 只回复表情/单字 | 降频，不视为意向 |

## 5. 合规示例

**可以**：

```text
周一 10:00  回答客户咨询（客户主动）
周三 19:30  补货通知（由头：上次问的码到了）
周五 20:00  活动邀约（客户此前问过同品类）
```

**不可以**：

```text
周一 09:00  群发活动
周一 15:00  再发一次"记得看"
周二 10:00  第三次"考虑得怎么样"
（同一客户 3 天 3 次，且后两次没有新由头）
```

## 6. 特殊情形

- **客户主动催**：不受频控限制，但要一次说清，不挤牙膏；
- **售后/服务消息**：不计营销频控，但不能夹带促销；
- **大促期间**：可临时上调到 3 次/周，需负责人书面确认，活动后恢复；
- **高客单客户**：频次更低（≤ 1 次/周），内容更具体；
- **群体标签冲突**：以更严格的频控为准。

## 7. 记录

每次触达记录：时间、渠道、由头、内容摘要、客户反应。
月底统计：触达数、回复率、退订率、投诉数。退订率上升，先降频，不要换话术硬试。
