# 阶段话术骨架

骨架不是逐字稿。用的时候替换括号里的内容，保留结构。

## 1. 新客（24 小时内）

**目标**：破冰，拿到第一个需求信息。

```text
"您好，我是[店]的[名字]。看到您是从[来源]来的～
您这次主要想看[品类]吗？我按需求给您挑，省得刷屏。"
```

成功标志：客户回了品类/场景/预算中的任意一项。
失败处理：不回就不追第二条；48 小时后用"新品/活动"由头一次，仍无回应转培育。

## 2. 高意向（24 小时内）

**目标**：补齐最后一个成交条件（尺码/城市/颜色），推进下单。

```text
"您要的[商品] [颜色/码] 还有 [数量]。
您收货城市是[城市]吗？我核对下[时间]前能不能到。"
```

成功标志：客户确认尺码或下单。
失败处理：客户犹豫 → 给两个选项 + 保障（退换/留货），不要降价。

## 3. 意向（48 小时）

**目标**：缩小选择，给证据。

```text
"上次您说怕[顾虑]，我找了两条对比：
① [A]：[差异一句]
② [B]：[差异一句]
和您情况像的客户多选[?]，您更看重[?]？"
```

成功标志：客户开始比较或提问。
失败处理：客户只回"再看看" → 给一个具体由头（周四上新），然后停 3 天。

## 4. 已购（7 天）

**目标**：确认满意，拿反馈与复购线索。

```text
"[商品]穿着还合适吗？[具体细节，如腰头]会不会勒？
如果有不合适，7 天内可以换，我来帮您处理。"
```

成功标志：客户给反馈（好评或问题）。
失败处理：客户不回 → 不追；30 天复购节点再触达。

## 5. 复购（30 天）

**目标**：二次购买或带新。

```text
"[商品]最近配了[搭配/新品]，和您那条是一个版型。
老客这周有[权益]，需要我帮您留吗？"
```

注意：权益属于 B 级，必须先确认力度与范围。

## 6. 沉睡（30 天一次，最多 2 次）

**目标**：唤醒，或确认进入不打扰。

```text
"好久没见～这周到了[新品]，和您之前买的[品类]是一路的。
不需要的话回我一句，我就不打扰了。"
```

成功标志：客户回复（哪怕拒绝）。
失败处理：2 次无回应 → 标记不打扰，停止。

## 7. 活动后（进群未下单 / 到场未成交）

```text
"昨天群里说的[问题]，我单独给您确认下：
[答案一句]。需要的话我帮您留到[时间]。"
```

不要群发"昨天没买的今天可以买"，要针对他在群里问过的具体问题。

## 8. 通用收尾

```text
"不急，您先忙。需要的时候跟我说一声就行。"
```

给对方一个不需要回复的出口，比"期待您的回复"更有效。
