# 复盘与规则提炼

复盘不是"这周谁做得好"，是**把一次有效的判断，变成下次谁都能用的规则**。

## 何时使用

- 周/月复盘，要看哪些动作有效；
- 某条话术突然不灵了；
- 销冠有一套自己的判断，想沉淀下来；
- 新人培训，需要可执行的规则而不是"多练"；
- 活动结束，要总结可复用的部分。

## 输入

对话样本（成功与失败都要）、结果数据（回复/进群/下单）、团队反馈、现有规则卡。

只有成功案例时，先补失败样本；没有对照，无法判断因果。

## 原则

1. **单案例不立规则。** 至少 3 个相似案例，或 1 个强证据（客户明确说出原因）。
2. **相关不等于因果。** 成交前发了图，不代表图带来成交；可能客户本来就要买。
3. **区分人与规则。** 是执行的人不行，还是规则本身错了。
4. **先影子运行。** 新规则先只记录不执行，观察 1–2 周再放开。
5. **规则要能回滚。** 每条规则有版本号、生效时间、下线条件。

## 第一步：把结果分层看

不要笼统说"转化率下降"。拆开：

| 层 | 看什么 | 常见问题 |
| --- | --- | --- |
| 触达 | 发了多少、送达多少 | 发得少，还是没发对 |
| 回复 | 回复率、首次回复时长 | 话术问题，还是时机问题 |
| 推进 | 追问后是否给出方案 | 需求没拆清 |
| 成交 | 下单率、客单价 | 价格、信任、库存 |
| 售后 | 退换、投诉 | 承诺过度、尺码不准 |

找到**变化最大的那一层**，再看那一层的对话。

## 第二步：找对照

同一时间、同一客群，比较：

- 有效 vs 无效的对话，差在哪一句；
- 老销售 vs 新销售，判断差在哪一步；
- 改版前 vs 改版后，哪个动作变了。

没有对照，就只写"观察"，不写"结论"。

## 第三步：提炼规则候选

一条规则必须回答五个问题：

```text
什么时候触发？（条件，可观察）
做什么？（动作）
说什么？（话术，可选）
什么情况下不适用？（例外）
凭什么？（证据 + 置信度）
```

示例：

```yaml
id: rule-2026-11-014
触发: 客户问“有没有不勒腰的”且预算 ≥ 300
动作: 优先推荐高腰宽腰头款，附 1 张腰头特写
话术: "这版腰头加宽 2 厘米，坐着不勒；您平时穿 M 还是 L？"
例外: 客户明确要低腰 / 预算 < 300
证据: 11 月 3 个案例，2 个下单；反例 1 个（客户要低腰）
置信度: 中（3 例，样本小）
状态: 影子运行
```

## 第四步：反例检验

每条候选规则，主动找 3 个可能不成立的情况：

- 换一个品类还成立吗？
- 换一个价格带还成立吗？
- 老客和新客反应一样吗？
- 如果客户正在投诉，这条还适用吗？

找不到反例，不代表规则对，可能只是样本太少。

## 第五步：写回建议

| 建议 | 条件 |
| --- | --- |
| 新增 | 证据 ≥ 3 例，反例可解释，负责人确认 |
| 修改 | 现有规则在特定条件下失效，有对照 |
| 下线 | 连续 2 周无效，或引发投诉 |
| 保留观察 | 证据不足，继续记录 |

写回前必须说明：影响哪些客户、哪些动作、是否需要重新授权。

## 输出格式

```markdown
## 复盘：11 月第二周

### 事实
- 触达 320，回复 96（30%），低于上周 38%
- 回复后给方案的比例 62%，高于上周 55%
- 成交 18 单，客单 412

### 观察
- 回复率下降集中在“新品上架”群发（12%），一对一跟进仍是 41%
- 给方案的对话成交率 29%，未给的 6%

### 规则候选
1. rule-2026-11-014（见上）
2. …

### 反例与风险
- 案例 7：客户要低腰，推荐宽腰头后流失
- 群发文案与一对一话术混用，可能是回复率下降的原因

### 建议
- 新增 rule-014，影子运行 2 周
- 群发文案单独建规则，不与一对一混用
- 下周补 10 个失败样本再评估
```

## 失败模式

| 现象 | 问题 | 纠正 |
| --- | --- | --- |
| 把个案当规律 | 样本 1–2 个 | 标注"观察"，不写规则 |
| 只看成交对话 | 幸存者偏差 | 补失败样本 |
| 规则写成口号 | "要真诚""要专业" | 改成可观察的条件与动作 |
| 一次改太多 | 无法归因 | 一次只改一条，留对照 |
| 规则上线不跟踪 | 不知道有没有用 | 设 2 周观察期与回滚条件 |
