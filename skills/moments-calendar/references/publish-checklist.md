# 发布前后核对清单

## 1. 发布前（缺一项就不发）

### 内容

- [ ] 与负责人确认的版本逐字一致（不是"意思差不多"）；
- [ ] 只讲一个主题，没有把新品、活动、口碑混在一条；
- [ ] 价格、折扣、赠品有明确授权；
- [ ] 库存、时效、活动时间已核实；
- [ ] 没有绝对化用语、功效承诺、诱导分享；
- [ ] 错别字、尺码、日期、地点已核对。

### 素材

- [ ] 图片/视频清晰，比例正确；
- [ ] 人脸、订单、聊天截图有授权或已脱敏；
- [ ] 没有其他品牌的 logo 或水印；
- [ ] 海报信息与文案一致。

### 执行

- [ ] 发布时间在客群活跃时段，不在免打扰时段；
- [ ] 可见范围正确（全部/分组/仅客户）；
- [ ] 有人负责承接私信与评论；
- [ ] 发布人知道"出问题找谁"。

## 2. 发布后（当天）

- [ ] 是否按计划时间发出；
- [ ] 发出的内容与确认版一致（截图留痕）；
- [ ] 评论/私信是否在 2 小时内有人回；
- [ ] 涉及价格的问题是否已转一对一；
- [ ] 负面评论是否已转人工，未被删除或争辩。

## 3. 发布后（一周）

| 记录项 | 用途 |
| --- | --- |
| 每条触达人数 | 判断覆盖面 |
| 点赞/评论/私信数 | 判断内容吸引力 |
| 私信转咨询数 | 判断承接质量 |
| 下单数/金额 | 判断转化 |
| 删除/拉黑数 | 判断是否打扰 |

不要只看点赞。点赞高、私信少，说明内容好看但不解决问题；私信多、下单少，说明承接或产品有问题。

## 4. 出错时

| 错误 | 处理 |
| --- | --- |
| 价格发错 | 立即隐藏/删除，发更正说明，不狡辩；同步所有承接人 |
| 发了未授权图片 | 立即删除，联系当事人道歉，记录事件 |
| 时间/地点写错 | 更正并单独通知已报名的人 |
| 内容引发负面 | 不删评、不对骂，转人工，统一口径 |
| 发错分组 | 评估覆盖面，必要时逐一说明 |

每次出错写进复盘：哪一步没拦住，下次加哪个检查项。

## 5. 留痕

保存：确认版截图、发布时间、实际内容截图、互动记录、承接记录。
没有留痕，就无法证明"发出去的"和"确认过的"一致。
