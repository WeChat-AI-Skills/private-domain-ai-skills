# 内容支柱与文案库

## 1. 六个支柱

### 新品

回答"为什么现在要买"。

- "腰头加宽了 2 厘米，坐下不勒——这是这版改的第一处。"
- "同一版型做了三个长度，155 和 170 都能穿。"
- "上周试版的 6 个客户，5 个说比旧版舒服。"

### 搭配

降低"买回去不会穿"的顾虑。

- "一条直筒，周一配衬衫、周三配针织、周五配卫衣。"
- "同色系三件套，早上不用想搭配。"
- "裤脚卷两折是九分，放下来是全长。"

### 场景

让客户对号入座。

- "早八地铁坐四十分钟，起身膝盖后面全是褶——这条不会。"
- "办公室空调 26 度，一条薄针织刚好。"
- "接孩子放学，蹲下起身不走光。"

### 口碑

提供证据，不伪造。

- "老客返图（已授权）：同一条裤子，三个身高。"
- "这个月第 4 个回购同款的客户。"
- "退货原因里，'尺码不合适'从 18% 降到 7%。"

### 幕后

建立信任，解释"为什么值"。

- "打版第三次才把腰头弧度调对。"
- "面料商同一块布，我们选了克重更高的那批。"
- "质检抽检 10%，线头直接退回。"

### 活动

制造时点，不制造焦虑。

- "周六下午 2 点试穿会，带平时穿的裤子来对比。"
- "老客专享价到周日，需要的私信我留货。"
- "群里会讲尺码，来不了也能看记录。"

## 2. 开头钩子（第一句）

| 类型 | 例子 |
| --- | --- |
| 具体场景 | "早八地铁坐四十分钟……" |
| 反常识 | "贵 40 块，但退货少了一半。" |
| 客户原话 | "'有没有不勒腰的'——这周被问了 9 次。" |
| 细节 | "腰头加宽 2 厘米，是这版唯一的改动。" |
| 对比 | "旧版 vs 新版，差别在坐下那一下。" |
| 时间 | "周四到货，只有 60 条。"（需属实） |

不要用："新品上市""火爆开售""最后一天"。

## 3. 文案长度

- 一条朋友圈：60–120 字，最多 3 段；
- 超过 150 字，客户在"全文"前就划走了；
- 长内容放公众号/群，不在朋友圈硬塞。

## 4. 十条不要写

1. 全网最低 / 最好 / 第一；
2. 保证显瘦 / 保证不掉色；
3. 最后 3 件（不实）；
4. 不转不是中国人 / 转发领券；
5. 伪造聊天记录、订单、评价；
6. 未授权的客户照片、孩子照片；
7. 医疗、治疗、功效承诺；
8. 贬低同行；
9. 制造焦虑（"再不买就晚了"）；
10. 连续三条同一商品。

## 5. 一条文案的自检

- [ ] 第一句能让人停下来吗？
- [ ] 只讲了一个卖点吗？
- [ ] 有具体细节（数字、场景、原话）吗？
- [ ] 有下一步动作吗？
- [ ] 有没有不能说的话？
- [ ] 客户读完，知道这条跟他有什么关系吗？
