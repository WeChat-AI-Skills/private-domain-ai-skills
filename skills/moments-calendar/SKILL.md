# 朋友圈内容与排期

朋友圈不是广告位，是**客户愿意继续留着你的理由**。
一条目标进来，先排节奏，再写文案——顺序反了就会刷屏。

## 何时使用

- 老板给一句话目标："这周推秋季通勤新品，主推直筒裤，别刷屏"；
- 要写单条朋友圈文案或海报 brief；
- 活动前要预热、活动中要播报、活动后要收尾；
- 朋友圈发得太密或太散，需要重新排节奏；
- 发布前要核对"发出去的"和"确认过的"是否一致。

## 输入

一句话目标、主推商品/活动、客群、老板偏好（频率、语气、是否露价）、可用的素材（图、视频、评价）。

缺素材时，只给文案与拍摄 brief，不假装有图。

## 第一步：把一句话拆成三件事

| 问题 | 例子 | 影响 |
| --- | --- | --- |
| 这周只推什么 | 秋季通勤直筒裤 | 主题不超过 1 个 |
| 对谁说话 | 30–40 岁通勤女性 | 语气与场景 |
| 老板的边界 | 别刷屏、不露价、不夸大 | 频率与文案 |

"别刷屏"要翻译成规则：**一周 3 条，间隔 ≥ 2 天，同一商品不超过 2 条。**

## 第二步：选内容支柱

一周选 2–3 个支柱，不要全用：

| 支柱 | 作用 | 例子 |
| --- | --- | --- |
| 新品 | 给购买理由 | 直筒裤上新，腰头加宽 |
| 搭配 | 降低想象成本 | 一条裤子三种通勤穿法 |
| 场景 | 让客户对号入座 | 早八地铁不皱的裤子 |
| 口碑 | 提供证据 | 老客返图/复购记录（需授权） |
| 幕后 | 建立信任 | 打版、选面料、质检 |
| 活动 | 制造时点 | 周六试穿会、限时权益 |

规则：**一条朋友圈只说一件事。** 新品 + 活动 + 口碑塞在一条里，等于什么都没说。

## 第三步：排期

```markdown
## 本周排期（11-11 至 11-17）
目标：主推秋季通勤直筒裤，不刷屏

| # | 时间 | 支柱 | 主题 | 素材 | 互动动作 | 授权 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 周二 12:00 | 新品 | 直筒裤上新：腰头加宽 | 平铺图 1 张 | 评论区问尺码 | B |
| 2 | 周四 19:30 | 搭配 | 一条裤子的三种通勤穿法 | 3 张上身图 | 引导私信 | B |
| 3 | 周六 10:00 | 场景 | 早八地铁不皱 | 15 秒视频 | 点赞老客 | B |
```

规则：

- 一周 3 条，间隔 ≥ 2 天；
- 发布时间固定在客群活跃时段（默认 12:00 / 19:30 / 10:00，可按数据调）；
- 同一商品不超过 2 条，第 3 条换角度；
- 活动期间可加到 4 条，活动结束恢复；
- 排期先给负责人确认，再进入发布队列。

## 第四步：写文案

结构：

```text
钩子（场景/问题，1 句）
→ 具体利益（只讲 1 个，1–2 句）
→ 证据（细节/评价/对比，1 句）
→ 行动（评论/私信/到店，1 句）
```

示例：

> 早八地铁坐四十分钟，起身膝盖后面全是褶。
> 这条直筒把腰头加宽了 2 厘米，坐着不勒，站起来还是直的。
> 面料是带 3% 弹力的斜纹，昨天有客户穿着开了一天会。
> 码数问题评论区问我，我一个个回。

要点：

- 第一句决定别人停不停，不要以"新品上市"开头；
- 一条只讲一个卖点，讲透；
- 不写"全网最低""保证显瘦"；
- 价格是否露出，按老板授权；不露价时用"私信问价"；
- 表情符号 ≤ 2 个，不堆砌。

## 第五步：海报 / 素材 brief

给设计或自己拍，都要写清：

```text
尺寸：1080×1440（朋友圈竖图）
主体：直筒裤正面 + 腰头特写
必现信息：版型（直筒）、卖点（腰头加宽 2cm）、价格（是否露出）
风格：自然光、通勤场景、不要影棚白底
禁忌：不修瘦、不伪造评价、不使用未授权客户照片
交付：周二 10:00 前
```

## 第六步：互动规则

| 动作 | 规则 |
| --- | --- |
| 点赞 | 只给近 30 天有过对话的老客；每天 ≤ 20 个 |
| 评论 | 按对方动态写具体内容，不复制粘贴 |
| 涉及价格 | 不在评论区谈，转一对一 |
| 负面评论 | 不删、不争，转人工处理 |
| 客户私信 | 进入 `customer-intake`，不在评论区继续 |

互动是"维护关系"，不是"完成任务"。批量点赞会让人觉得被骚扰。

## 第七步：发布前核对

逐项打勾，任何一项不过就不发：

- [ ] 与负责人确认的版本逐字一致；
- [ ] 时间、可见范围正确；
- [ ] 价格/权益有授权；
- [ ] 图片没有未授权的人脸、订单、聊天截图；
- [ ] 没有绝对化用语、虚假承诺；
- [ ] 错别字、尺码、活动时间已核对；
- [ ] 有对应的一对一承接人（有人问，谁回）。

## 第八步：发布后核对

- 3 条是否按排期发出；
- 发出的内容与确认版是否一致；
- 谁点赞、谁评论、谁私信，是否留痕；
- 私信是否已转入接待；
- 哪条互动最好，记进下周排期参考。

## 输出格式

```markdown
## 本周朋友圈计划
目标：…
节奏：3 条，间隔 ≥ 2 天

### 排期表
（表格）

### 文案
1. 周二 12:00 …
2. 周四 19:30 …
3. 周六 10:00 …

### 素材 brief
…

### 互动与承接
…

### 待确认
- 价格是否露出
- 客户返图是否有授权
```
