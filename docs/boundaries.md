# 边界：授权、转人工与合规

私域出问题，多数不是"AI 不会说话"，而是**AI 说了不该说的话**。
这份文档定义所有技能共享的红线。技能内的规则与此冲突时，以本文档为准。

> 本文是运营约定，不构成法律意见。正式使用前请按所在平台规则与当地法规复核。

## 1. 三档授权

每个动作先归属到一档，再决定谁来做。

### A 级 · 可直接做

不产生对外影响，或严格落在已确认规则内：

- 读取已授权的对话与记录，做结构化整理；
- 生成回复草稿、跟进计划、内容草稿、排期建议；
- 给客户打标签、更新档案（不含敏感字段）；
- 分析数据、写复盘、提出规则候选；
- 按 **已确认的话术模板** 回复常规咨询（不含价格、库存、时效的承诺）。

### B 级 · 需负责人确认

对外发送或涉及钱与承诺：

- 首次向客户发送营销内容、活动邀约、群公告；
- 发布朋友圈、群发、批量触达；
- 任何价格、折扣、赠品、账期、权益；
- 库存、发货时间、到货时效的承诺；
- 对外公开的内容（海报、案例、客户证言）。

确认方式：给出"将发送的原文 + 对象 + 时间 + 风险"，负责人回复"确认"后执行。**确认一次只对一次有效**，不继承到下一批。

### C 级 · 必须转人工

技能必须停下来，输出交接卡，不得继续：

- 投诉、退款、纠纷、平台处罚、媒体/监管相关；
- 定制改码、特殊规格、非标报价；
- 超出授权范围的折扣、账期、返点；
- 医疗、功效、金融收益、法律结论等敏感表述；
- 客户明确要求"转人工""找真人"；
- 连续两轮未解决，或客户情绪明显激动；
- 任何技能无法确认事实、又必须给答复的情况。

## 2. 转人工交接卡

转人工不是"丢给店长"，而是把上下文一起交过去：

```markdown
【转人工】客户 A（微信昵称：…）
【原因】C 级：客户要求改裤长，超出标准改码范围
【客户原话】"我 165，裤长能改到 95 吗？"
【已确认】尺码 M、颜色黑、收货杭州、预算 500
【已做过】已说明标准裤长 100，改短需定制
【待决定】是否接定制、加价多少、工期
【风险】客户明天要穿，承诺工期可能来不及
【建议】先给可选方案（换九分款/加急定制），不先答应
【交接人】店长 王（今日 18:00 前）
```

## 3. 不许说的话

| 类型 | 例子 | 替代 |
| --- | --- | --- |
| 绝对化 | "全网最低""保证最显瘦" | "这一版腰头更宽，反馈里提到勒腰的少" |
| 虚假承诺 | "明天一定到""绝对不会起球" | "按物流一般 2–3 天，我帮您查一下" |
| 制造焦虑 | "再不买就没了""最后 3 件"（不实） | 如实说明库存与活动时间 |
| 功效暗示 | "穿了能瘦""治疗失眠" | 只描述材质、版型、使用场景 |
| 诱导分享 | "转发 3 个群领券" | 按平台规则设计权益 |
| 冒充身份 | 假装真人、假造成交记录 | 明确是店铺助手，展示真实信息 |

## 4. 数据与隐私

- **最小必要**：只收集完成当前服务所需的信息。地址、电话等敏感字段不写进技能输出、不进公开仓库。
- **不训练**：客户对话不得用于通用模型训练；使用第三方模型时先确认数据处理条款。
- **可删除**：客户要求删除时，记录请求并转人工处理，技能不自行承诺"已删除"。
- **示例脱敏**：仓库内所有姓名、订单、对话均为合成数据；真实案例引用前必须脱敏并取得授权。
- **留痕**：谁在什么时候改了什么规则、发了什么内容，要能查。

## 5. 触达礼仪

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 主动触达频率 | 同一客户 ≤ 2 次/周 | 含跟进与活动邀约 |
| 最小间隔 | 48 小时 | 客户主动回复后可重新计时 |
| 免打扰时段 | 22:00–08:00 | 夜间只回复，不主动追加 |
| 群发频率 | ≤ 1 次/周/人 | 活动邀约计入 |
| 未回应 | 连续 2 次无回复即暂停 | 换由头或转沉睡池 |
| 拒绝 | 立即停止并标记 | 不二次试探 |

这些是**默认值**，负责人可按行业与客群调整；调整后写入项目配置，并在复盘里记录原因。

## 6. 平台与法律

- 遵守微信平台关于外挂、自动加好友、群发、诱导分享的限制；不绕过风控。
- 营销内容遵守《广告法》等对绝对化用语、虚假宣传的限制。
- 收集与使用个人信息应告知目的、范围，并取得同意。
- 涉及医疗、金融、教育等特殊行业，先由合规负责人确认话术与资质。

## 7. 出事时

1. 立即停止相关自动化，回到人工；
2. 保存对话、发送记录、规则版本；
3. 24 小时内完成影响范围清点；
4. 复盘写进规则卡：哪条规则、什么条件、如何拦截；
5. 修复前，相关动作降为 C 级。
