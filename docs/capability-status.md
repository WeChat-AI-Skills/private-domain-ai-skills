# v1.0.0 能力状态

发布日期：2026-11-13。版本号表示本技能包的交付版本，具体企业运行能力按环境验收。

| 层级 | 本版本范围 | 验收方式 |
| --- | --- | --- |
| 技能文件 | 14 项，含业务判断、SCRM 操作与配套核验 | frontmatter、清单、安装后引用检查 |
| 安装与更新 | 复制安装、冲突保护、未修改副本更新 | 隔离目录安装及冲突/恢复测试 |
| 宿主识别 | Codex 为首个适配宿主 | 隔离 Codex skills/list 枚举 |
| 示例 | 咨询、朋友圈、活动 3 组合成案例 | 检查事实保真、时间、状态和计数边界 |
| 有赞本地核验 | 加购未购聚合脚本 | 合成数据自测；真实资料需客户授权 |
| SCRM 实际执行 | 提供上岗和操作流程 | 每个客户核对入口、权限、授权、提交及结果；本版本未证明客户现场已通过 |
| 其他宿主 | 支持指定安装目录 | 需逐宿主验证识别和行为 |
| MCP 服务端、商品上下架 | 尚未交付 | 取得实际接口及测试环境后推进 |

安装通过不证明业务连接可用。草稿完成、平台受理、排期、实际执行、客户阅读或成交分别记录。持续自动化需要真实调度器与运行证据，本包未启用任何客户自动任务。

本版本的具体检查结果见[发布验证](verification-v1.0.0.md)。
