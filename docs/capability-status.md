# 能力状态

当前版本 v1.3.0：原 15 项技能继续保留，新增 SCRM 操作包，共 16 项；7 类目录、28 节点、6 角色、3 工作流保持不变。提供连接/会话检查、页面操作档案和离线绑定/调用/结果核验。旧任务卡 1.0/1.1 与当前 1.2 继续可读；客户现场状态仍为 not_verified。具体证据见[本版验证](verification-v1.3.0.md)和[验证口径](evaluation.md)。

发布日期：2026-11-13。具体企业运行能力按环境验收；版本号不代表全部业务节点已接入。

| 证据层级 | 本版本范围 | 边界 |
| --- | --- | --- |
| 技能文件与静态结构 | 16 项入口，登记输入输出、依赖、资源及验证引用 | 结构正确不证明模型判断或业务执行正确 |
| 安装与宿主识别 | 完整复制、冲突保护、版本回执；Codex 为首个适配宿主 | 客户修改副本保留；其他宿主需单独验证 |
| 脚本与模拟 | 原有本地回执与 SQLite 模拟；新增 SCRM 绑定、调用/尝试/客户范围和结果阶段核验 | 全部离线，不认证凭据/授权，不调用生产 API |
| Agent 合成行为 | 各版分别保留实际输入、作答和判据，见对应验证记录 | 合成测试不证明全部提问、浏览器操作或所有宿主正确执行 |
| 有赞本地核验 | 原加购未购聚合脚本及合成自测 | 真实资料需客户授权、同窗口与可核对口径 |

| MCP 服务端、商品上下架、持续调度 | 后续计划 | 尚未交付或启用 |

草稿、平台受理、排期、实际发送/发布、客户已读/入群/成交分别记录。模拟器的单次/批次授权夹具不限制客户已有效授予的持续权限；真实系统仍须校验人员权限、联系意愿和动作范围。

## v1.2.0 架构范围

七类能力、28 节点和六个角色职责已纳入安装包，仍为 15 项技能。目录覆盖状态与客户环境执行状态分开；所有节点现场状态为 not_verified。

- 目录、职责、任务约定与工作流是可读取的资源，目录脚本不启动多 Agent 或连接业务系统。
- 默认可以由同一宿主按角色职责执行；真实委派、并发和长期调度需单独验收。
- 商品角色当前可整理已有商品事实与缺口；无独立上架技能和适配。候选名称不会进入安装清单。
- 本版本的新增验证见 [v1.2.0 记录](verification-v1.2.0.md)。v1.1.1 及更早记录只证明各自当时的范围。
