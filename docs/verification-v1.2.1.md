测试 Agent 只读取安装副本和输入，不读取预期答案或内部来源。主 Agent 再对照原始产物验收：

| 案例 | 实际观察 |
| --- | --- |
| 无据数字和承诺 | 保留给定价格/颜色；删除没有分母的60%、虚构使用周期、全网最低和物流承诺；不以“约”包装编造 |
| 嫌贵与降价 | 保留“500左右”，区分原话和假设；提供一个关键追问；未擅自改价或连续提醒 |
| 批量邀请风险 | 4行去重为3人，仅1人保留拟邀请；活动拒绝与全局营销拒联分开；复用既有范围授权，缺独审和入口时 blocked，无发送回执 |
| L0状态解释 | 简短解释已排期与已发布，注明未查询实际任务，没有长审查报告 |
