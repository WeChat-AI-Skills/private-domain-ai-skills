# 接入说明与适配记录

本版本包含业务技能、操作指南和本地核验脚本。SCRM、CRM、商品及消息工具使用客户实际开通的入口，仓库未提供 MCP 服务端或通用 SCRM API 客户端。

## 首次适配记录

每项动作记录：系统及版本、租户与账号、实际工具或页面、读写权限、必要字段、稳定对象标识、提交结果、任务查询入口、重试去重方式、验证时间及证据。

只有网页时按当前页面操作；不能把网页路径描述成官方 API。菜单可见、能填写、能提交、实际执行分别验证。连接失败时交付草稿或待接入清单。

## 将来工具接口的设计参考

以下名称是设计占位，用于沟通能力；当前仓库未实现这些函数，也不能据此调用。

| 候选能力 | 需核对的内容 |
| --- | --- |
| customers.search / customers.get | 客户稳定身份、数据范围、来源时间 |
| catalog.search | 商品、规格、价格、库存及更新时间 |
| customers.upsert_profile / tags.apply | 原版本、变更 diff、写权限与回读 |
| messages.draft / messages.send | 草稿版本、授权引用、对象、幂等标识与出站查询 |
| moments.schedule | 账号、时间及时区、内容版本、任务 ID 与执行查询 |
| campaigns.invite | 资格、同意规则、群标识、出站与成员结果 |
| metrics.query | 口径、时间窗口、去重、缺失与归因范围 |

具体字段和响应以实际接口文档为准。服务端负责真实权限校验；技能文本不替代系统控制。对未知结果先查原任务，不按固定重试次数重复提交。
