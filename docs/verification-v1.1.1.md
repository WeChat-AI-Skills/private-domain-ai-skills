# v1.1.1 公开分发验证

## 发布前检查

- 当前文件与 Git 可达历史检查：未发现所检索模式中的密钥、手机号、邮件地址或个人绝对路径；历史 README 内部来源链接已清理。扫描不是对所有可能敏感信息的绝对保证。
- 原始 Git 历史已在私有环境完整备份并校验。历史清理只修改旧 README 文档内容及后续提交标识，既有三个版本标签下的文件树保持一致；演示图片与原 MIT 声明保留。
- 仓库为唯一正式发布入口，历史 DeepSeek 仓库保持私有归档。

## 客户复现

按[快速开始](quickstart.md)在未登录 GitHub 的环境中克隆 v1.1.1，运行结构校验，再指定独立技能目录进行 dry-run 和安装，检查安装回执版本、15 项文件和宿主识别。升级只接管本包未修改的受管理副本。

真实 SCRM 账号、业务授权及客户现场执行需在各自环境单独验收，公开下载不授予业务系统权限。其他 Agent 宿主的识别仍需分别验证。
