# 客户 Codex 连接与操作 SCRM

当前版本 v1.3.1；v1.3.0 新增 `wechat-scrm-operator`，完整安装共 16 项技能。它提供本套 SCRM 的工具/会话检查、图文朋友圈与任务式好友消息操作指引，以及离线记录核验。真实客户部署尚未验证，首次使用需核对客户当前页面和权限。

## 安装后从这里开始

先按[安装说明](quickstart.md)安装固定版本并核对 Codex 识别。只需给 Codex 这条任务：

> 使用 $wechat-scrm-operator，复用我已提供的 SCRM 正式入口、已登录会话和业务范围，检查你现在能用的浏览器或桌面控制工具。只读核对企业、工作号、权限、当前页面和结果查询入口，只问缺少的必要信息，返回环境卡与可推进的任务。

第一次需要：客户自己的 SCRM 入口、正式登录、允许使用的工作号，以及 Codex 会话实际可用的控制工具。工具列表中没有相应能力时，Agent 应说明具体缺口；电脑装有浏览器或能打开网页，不代表该 Agent 能控制它。缺登录时由客户在正式界面完成，不把密码、验证码或会话凭据写入技能目录。

当前包不安装浏览器扩展、MCP 服务或常驻任务。按客户宿主官方支持的方法配置缺少的工具，再继续只读检查；不要求把客户账号交给维护者。可复用客户已有的获授权工具，不强制购买某一服务。

普通草稿任务无需连接 SCRM。已有正确会话、有效授权及可用操作工具时，Agent 继续在范围内操作；重新确认仅针对变化或缺失的部分。

## 第一条图文朋友圈

客户提供最终图文及图片顺序、测试工作号、绝对时间与时区、可见范围，以及适用的评论/位置等设置。可这样说：

> 使用已经绑定的测试工作号，按我确认的最终图文和时间创建这条朋友圈排期。先核对已有任务，提交后重开原任务核对保存配置，并在本次可持续覆盖的测试时间内查到期结果。

Agent 按实际菜单定位“发表朋友圈”，检查上传完成和日期控件实际值，提交一次并保存原任务标识。仅有排期记录时报告“排期已保存”；到期获得逐工作号发布证据后才报告发布结果。可见范围与延迟评论另行核验，不能由主任务成功推断。

如果工具超时、页面切到其他账号或找不到唯一原任务，先查原记录并保留未知，不能重建任务掩盖缺口。长时任务仍由 SCRM 的排期执行；Codex 关闭后不自动常驻核对。没有已授权调度能力时，保留待查任务并明确需要下次查询。

## 第一条指定好友消息

指定原工作号、稳定联系人、最终内容、时间窗口和有效授权。Agent 检查关系、拒联、人工接管及已发/待发任务，回读实际选中数为 1。提交后核对原任务，并查该对象的本次出站记录。

任务式“好友消息”与聚合聊天窗口即时回复是不同路径。当前操作包先提供前者，不能因任务菜单不见就自动切换聊天窗口发送。出站记录也不能证明客户已读、回复或成交。

## 支持与验证范围

| 项目 | v1.3.0 交付 | 使用时还需确认 |
| --- | --- | --- |
| 工具与只读上岗 | 操作指引、环境/绑定模板、缺口判断 | 客户实际工具、正确会话、租户与工作号 |
| 图文朋友圈 | 表单步骤、原任务修改/查询与发布回读方法 | 当前字段、权限、稳定标识与实际结果 |
| 指定好友任务消息 | 名单、时间、内容顺序与出站回读方法 | 当前页面、所选对象和消息状态 |
| 离线核验 | 绑定、调用、结果的结构/关联检查及合成样例 | 输入记录真实性、实际授权和平台结果 |
| 聚合聊天、视频/链接/视频号、点赞评论 | 功能边界与后续路径 | 未交付完整实操适配，不继承图文/任务消息验证 |
| 自动标签、回访规则、加好友、远程协助 | 未默认启用 | 独立操作定义、启停/恢复及具体授权 |
| 其他产品 API/MCP/CLI | 能力与绑定扩展约定 | 正式接口、适配实现及独立验收 |

现有群邀请、关系清理等技能保留。这套 SCRM 当前部署是否提供相应动作需另核；“删除好友记录”不是主动删除能力，转账记录不是付款接口。只有数据读取授权时不做写入或导出全库。

## 修改已有排期

朋友圈与好友消息都遵循[提交回执第5条](../.agents/skills/wechat-scrm-onboarding/references/operation-receipts.md#scheduled-task-changes)：仅改内容时用原任务ID打开「修改」，保存后重开同一任务，确认新内容/排版及原账号、收件人或可见范围、时间。无修改入口、修改失败或读回不一致即停在原任务报告，保存不明先查；不以取消重建、复制配置提交或重发替代。只有整批更换名单/账号且原任务无法修改，才报告企业指定负责人并等待决定；明确获准取消并重建后，先确认旧任务已取消且未执行，再建替代任务。

## 记录与升级

客户真实绑定、工作资料和执行证据保存在客户工作区，位于技能目录之外。模板只作结构示例；离线检查通过不能标为“已连接”“已获授权”或“业务成功”。

新包通过现有任务/证据引用关联调用记录，保留任务卡 1.0/1.1/1.2，沿用 A卷及 L3 独立审查、签核与恢复要求。普通任务使用必要记录，不为每次点击创建复杂表单。

16 项版本不能直接用 15 项旧包覆盖降级，安装器会保护性拒绝。升级前保留完整原副本与回执；回退时在独立目录恢复旧副本或安装旧包，核对宿主识别后切换目录，避免同时加载同名技能。客户工作区数据与新契约记录不随降级转换。
