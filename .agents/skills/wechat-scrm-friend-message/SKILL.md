# SCRM 好友消息

执行前阅读[提交与回执](../wechat-scrm-onboarding/references/operation-receipts.md)。核对原工作号、当前好友关系、拒联、已有触达、待发任务及人工接手状态。

1. 从「微信管理 → 群发配置 → 好友消息」进入「通讯录」。单人任务回读选中数为 1。名单或标签任务核对实际列表、勾选数和去重数，处理差异后推进。
2. 设「消息开始发送时间」与「任务执行时间区间」，窗口须覆盖开始时间。核对「每条消息间隔时间」「好友发送间隔」及额度。对可能次日续跑的任务，先核对有效期。
3. 按最终标点、换行和顺序录入。固定顺序的文字、图片、小程序通过「+发送多条」建独立消息块，核对模式、上传完成情况及已收藏小程序的标题与缩略图。
4. 获准后提交一次，在「任务列表」回读原条目的账号、对象、时间、状态、进度与「查看内容」。内容折叠时可用「使用任务配置」核对实际输入和选择项，随后返回原任务。复用表单仅用于此项核查。
5. 核实执行时查原账号按稳定对象保存的本次出站记录、时间及结果。即时发送以当前指令明确要求及存在适用的正式即时入口为条件。
