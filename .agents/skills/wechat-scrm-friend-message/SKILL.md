# SCRM 好友消息

接令时按[A卷上岗原则](../private-domain-ops/references/a-volume-onboarding.md)核对事实、真实问题与失败路径；按风险调整留证，同一任务复用已完成判断与有效授权。

本场景停止条件：对象或拒联范围不明、当前频控未核对时暂停受影响发送；只采用已批准的规则，不默认隔 24 小时可重发。提交前核对最终内容事实和授权，超时或结果未知先查原任务。参照[重复触达](../private-domain-ops/references/failure-cases.md#case-03)、[拒联范围](../private-domain-ops/references/failure-cases.md#case-08)。

执行前阅读[提交与回执](../wechat-scrm-onboarding/references/operation-receipts.md)。**已排期任务的修改统一遵循[第 5 条](../wechat-scrm-onboarding/references/operation-receipts.md#scheduled-task-changes)**：仅改文案、图片、链接或小程序卡片时，在原任务「修改」并原地保存；重开同一 ID 核对内容排版，确认账号、收件人和时间不变。无修改入口、修改失败或读回不一致时停在原任务并报告，不取消重建或重发。整批换名单/账号且原任务确实无法修改时，按第 5 条报告企业指定负责人，等待明确决定。

核对原工作号、当前好友关系、拒联、已有触达、待发任务及人工接手状态。

本套 SCRM 的工具连接及任务消息字段见 [SCRM 操作包](../wechat-scrm-operator/SKILL.md)。任务式消息与聚合聊天即时回复分别核验，不能因任务入口未找到而改用聊天窗口发送。

以下步骤用于新任务及回读；修改已有排期先按第 5 条处理，不重新走新建提交。

1. 从「微信管理 → 群发配置 → 好友消息」进入「通讯录」。单人任务回读选中数为 1。名单或标签任务核对实际列表、勾选数和去重数，处理差异后推进。
2. 设「消息开始发送时间」与「任务执行时间区间」，窗口须覆盖开始时间。核对「每条消息间隔时间」「好友发送间隔」及额度。对可能次日续跑的任务，先核对有效期。
3. 按最终标点、换行和顺序录入。固定顺序的文字、图片、小程序通过「+发送多条」建独立消息块，核对模式、上传完成情况及已收藏小程序的标题与缩略图。
4. 获准新建后提交一次，在「任务列表」回读原条目的账号、对象、时间、状态、进度与「查看内容」。内容折叠时，「使用任务配置」仅用于核对已保存的内容和勾选项，随后返回原任务；不在复制表单中修改、重新提交或重发。
5. 核实执行时查原账号按稳定对象保存的本次出站记录、时间及结果。即时发送以当前指令明确要求及存在适用的正式即时入口为条件。
