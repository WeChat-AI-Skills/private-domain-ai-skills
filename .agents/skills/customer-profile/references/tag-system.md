# 标签体系

优先使用企业已有字典。新增候选标签给出定义、取值、依据、会改变什么动作及复核时间。

| 维度 | 示例 | 条件 |
| --- | --- | --- |
| 来源 | 来源:门店 | 有可核对渠道记录 |
| 品类 | 品类:裤装 | 有明确需求或订单 |
| 需求 | 需求:通勤 | 客户明确表达 |
| 偏好 | 偏好:宽松腰 | 保留原话 |
| 行为 | 行为:问过尺码 | 有记录及时间 |
| 服务 | 服务:售后待处理 | 有实际工单状态 |
| 权益 | 权益:会员 | 已核对权益有效期 |

“易怒”“很好说话”等人格判断不作运营事实；一次询价不自动生成“价格敏感”。同义词归一保留原词和映射。当前意图与过去历史冲突时保留两者的时间与范围。

已拒联客户不因新增营销标签重新进入触达名单。新增、改名、合并、清理标签先形成变更建议，系统写入按实际授权执行；标签到期不自动删除业务记录。
