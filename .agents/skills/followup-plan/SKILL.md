# 客户跟进计划

接令时按[A卷上岗原则](../private-domain-ops/references/a-volume-onboarding.md)核对事实、真实问题与失败路径；按风险调整留证，同一任务复用已完成判断与有效授权。

本场景停止条件：被拒绝范围的营销立即停；身份、跨账号触达历史或当前频控不明时暂停受影响触达。不能把 24 小时或任何示例间隔当作默认重发许可；提交结果未知先查原任务。参照[重复触达](../private-domain-ops/references/failure-cases.md#case-03)、[拒联与必要售后](../private-domain-ops/references/failure-cases.md#case-08)。

输入：获授权的客户档案、对话与待办、业务目标、当前有效商品或活动信息、触达规则。

1. 先看客户是否拒联、已被人工接管、投诉未解决、已有待发任务或刚收到其他账号触达。身份不清和历史缺失单列。
2. 每次跟进说明“为什么现在联系”：回答未解决的问题、已核实的补货、适用活动或客户约定。缺少真实理由时建议等待。
3. 按[频率规则](references/frequency-rules.md)使用客户已批准的频次、时区和窗口。示例数值只用于拟计划，不当作平台额度或持续授权。
4. 形成计划：客户引用、绝对日期及时区、渠道、依据、草稿、负责人、授权状态、停止条件。根据[阶段话术](references/stage-playbook.md)组织内容，不虚构留货和服务承诺。
5. 已明确要求发送且必要条件齐全时，衔接 [SCRM 好友消息](../wechat-scrm-friend-message/SKILL.md)；只要求排计划时停在草稿。参考[授权规则](../private-domain-ops/references/authorization.md)。
6. 客户回复、购买、拒绝或规则变化后更新未执行计划。部分失败只核对剩余对象；提交结果未知先查原任务。

输出：计划表、可执行范围、待补项、已执行证据与待核结果。停止营销不等同于删除好友；不因客户沉默自动启动清理。
