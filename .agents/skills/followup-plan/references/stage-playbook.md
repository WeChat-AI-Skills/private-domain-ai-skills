# 阶段与话术骨架

下面按目的组织草稿；阶段本身不授予发送权限或决定固定触达周期。

| 目的 | 可用骨架 | 先核对 |
| --- | --- | --- |
| 新咨询 | 复述当前需求 → 一个必要问题 | 原话和现有答复 |
| 补齐推荐信息 | 说明已核实候选差异 → 尺码/时间问题 | 商品、库存和服务资料 |
| 补货通知 | 您之前问的规格有了新情况 → 是否仍需要 | 当前库存、历史需求、触达许可 |
| 已购服务 | 询问使用问题 → 说明适用服务入口 | 实际订单、售后条款 |
| 复购或活动 | 联系客户已有需求 → 给适用信息 | 活动有效期、权益、拒联状态 |
| 活动后答疑 | 回答活动中未解决的问题 | 原问题和已确认答案 |

需要留货、加急、运费承担、赠品或定制时，核对相应规则与授权后再写。无回复时遵守[频率与停止规则](frequency-rules.md)，不自动增加触达次数。
