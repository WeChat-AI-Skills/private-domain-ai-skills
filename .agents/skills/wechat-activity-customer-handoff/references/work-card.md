# 工作卡与回执

| 字段 | 填写要求 |
| --- | --- |
| 事件 ID、客户引用 | 使用任务系统里的稳定引用，卡片只保留处理所需字段 |
| 问题与活动 | 概括客户问了什么，附活动 ID、规则版本和有效期 |
| 核实依据 | 记录来源和核实时间。把可确认事实和待核实事项分别写入对应字段 |
| 建议与草稿 | 写处理理由、下一步。满足受理和证据条件时附草稿及版本 |
| 负责人、接班人、截止时间 | 交接卡记录待办事项和原负责人已告知客户的内容。接手确认单独记录 |
| 审核 | 记录审核人、时间、结论以及对应的草稿版本 |
| 人工动作与回执 | 记录实际执行人、时间、渠道回执或人工记录引用。异常时记录原动作查询结果 |
| 客户结果与后续 | 记录已确认结果、转交待接手、客户无回应等真实状态，以及下次动作或暂停原因 |

工作卡从待办进入待审核。审核后的任务可进入待执行或转交。已执行以动作回执为依据，已接手以接班人确认为依据。收到回执并完成约定事项后结案，渠道失败和回执缺失保留在各自状态。
