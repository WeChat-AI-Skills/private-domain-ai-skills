# 合成验收案例

示例时间为 2099 年 11 月 13 日 15:00，时区 Asia/Shanghai。客户引用、活动与事件均为合成。

| 场景 | 已知输入 | 预期结果 |
| --- | --- | --- |
| 主动问礼赠是否属实 | EVT-001，客户 C-01 在范围内，授权有效。活动 G-01 规则 v2 在当天有效，获批核实入口为品牌店铺 App 的「会员活动」页面。没有库存依据 | 生成待审核草稿，指明核实方式，保留库存未知 |
| 同名且对象冲突 | EVT-002，两个候选客户引用均与展示昵称相符，授权只覆盖其中一个 | 暂缓对客草稿，转负责人确认身份 |
| 授权已撤回 | EVT-003，身份明确，活动有效，客户已撤回适用授权 | 记录暂停和撤回原因，省略对客草稿及执行安排 |
| 规则冲突 | EVT-004，两份来源对同一时段给出相反领取条件，当前批准版本查不到 | 记录冲突和待核实依据，转人工确认 |
| 已审批但没有回执 | EVT-005，草稿 v1 已批准，渠道没有可回读发送记录 | 保留待核对，查原动作，避免重复分派或发送 |
| 接班未确认 | EVT-006，原负责人已发出交接，接班人未确认 | 记录等待接手，保留负责人和截止时间 |
