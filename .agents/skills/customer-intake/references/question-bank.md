# 追问库

选会改变下一步的必要问题，复用客户已说的信息。以下为问法示例，按实际业务改写。

| 场景 | 可问的问题 | 用途 |
| --- | --- | --- |
| 尺码与版型 | 平时穿什么码？更在意腰部还是裤长？ | 结合商品尺码表核对 |
| 到货时限 | 哪天要用？收货城市是哪里？ | 查当前库存、发货截止与物流承诺 |
| 预算 | 您说的“500 左右”是否还有可接受的范围？ | 仅在推荐确实受影响时询问 |
| 送礼 | 给谁使用？是否需要包装？ | 确认可服务范围 |
| 家居大件 | 位置尺寸和安装条件是什么？ | 核对商品及服务条件 |
| 食品 | 几个人使用？哪天需要？ | 核对规格与配送，不预设冷链天数 |
| B2B | 当前最想解决什么问题？谁负责决定？ | 确定目标与交接人 |

健康、儿童等信息只在业务必要且获授权时询问，相关专业判断交由合适人员。客户要求人工或正在投诉时优先交接，避免继续销售问卷。
