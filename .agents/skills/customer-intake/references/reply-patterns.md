# 回复模式

以下是结构示例。商品、库存、价格、优惠、退换、运费、留货与回复时限均以当前事实和授权为准。

| 情况 | 回复结构 |
| --- | --- |
| 明确场景 | 复述原话中的场合与限定词 → 提供有依据的候选 → 必要追问 |
| 问库存但未取得数据 | 说明需要核对具体规格库存 → 询问规格；不先回答“有货” |
| 比价 | 确认比较对象 → 根据资料说明差异 → 给可核实的选择 |
| 犹豫 | 尊重决定 → 给一个有依据的信息或约定；无回应时按业务规则暂停 |
| 售后或要求真人 | 记录问题 → 整理交接 → 依据接手回执报告状态 |

合成示例输入：“周末有活动，预算 500 左右，想要腰部宽松点的裤子。”

可用草稿：“收到，周末活动穿、预算 500 左右，想要腰部宽松些。您具体哪天要用、收货城市是哪里？我核对商品和配送后再给您建议。”

没有库存或物流证据时，不承诺数量、到货日期或留货。已经下单、已经发送、已经交接必须有对应回执。
