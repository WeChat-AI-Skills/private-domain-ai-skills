# SCRM 现有客户群邀请

接令时按[A卷上岗原则](../private-domain-ops/references/a-volume-onboarding.md)核对事实、真实问题与失败路径；按风险调整留证，同一任务复用已完成判断与有效授权。

执行前阅读[提交与回执](../wechat-scrm-onboarding/references/operation-receipts.md)。先核对「添加」的实际效果为发送原生邀请卡。直接添加、新建群或群发消息有各自的入口、权限和授权范围。

1. 用群类型、稳定群标识、群全名及归属工作号定位唯一目标群。确认工作号在群内、有权限且群容量允许。在「聊天」切到原工作号，进入「群成员 → 添加」。
2. 按企业规则逐人核对资格。需要客户同意或先通知时查实际回复或出站证据。排除已入群、已有正确邀请、上次结果待查、拒联及身份存疑的对象。
3. 用当前成员资料或好友详情的「好友所在群」查证成员身份。采用搜索无结果作辅助证据前，先用同一工作号下的已知成员验证搜索可命中。选择器可选、同名昵称和群人数变化仅作线索。
4. 按稳定标识逐人核对实际勾选项和人数。按已授权批次与额度提交一次，记录群、工作号、人数、受理时间和任务标识。历史结果未知时先查原会话。
5. 在原工作号的逐人会话核对正确群卡片、时间和出站状态。通过当前成员明细及稳定身份另计已入群。

给现有群发定时消息的历史入口为「微信管理 → 群发配置 → 群消息」。使用前在企业环境核对真实入口、账号、群、时间、执行区间和消息顺序，再按对应动作授权处理。
