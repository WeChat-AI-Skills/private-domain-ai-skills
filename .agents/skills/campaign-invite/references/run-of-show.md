# 活动议程与邀约草稿

议程模板：活动前公告 → 开场说明目标及规则 → 已确认的内容或答疑 → 适用权益说明 → 未解决问题与后续安排。

填写绝对时间及时区、形式、负责人、容量、材料状态及承接渠道。线下名额与线上群容量分别核对；不能将两者混为一个限制。

邀约结构：已核实的客户需求 → 本次活动可以解决的事项 → 时间与形式 → 询问是否愿意参加。只有实际安排了试穿、录像、视频咨询、留货或专享权益时才能写进邀请。

同意后核对群与身份，再按实际权限发送邀请；出站后查成员状态。客户未回复、链接状态不明或群已满时先核查，不自动重发。

群公告、群发、成员移出、关闭入群或解散群是独立动作。活动结束先给群处置与回访建议，按负责人已有授权处理。

交接记录未答问题、已做动作、当前状态、负责人和已确认时限；没有接手回执则保留待接手。
