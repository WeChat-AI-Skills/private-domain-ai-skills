# SCRM 朋友圈图文排期

执行前阅读[提交与回执](../wechat-scrm-onboarding/references/operation-receipts.md)。

1. 核对最终正文、配图原件和顺序、授权工作号、绝对发布时间、业务时区及可见范围。附评论时核对评论正文和延迟。其他开关按本条要求或企业已批准的默认值。
2. 从「朋友圈管理 → 发圈管理 → 发表朋友圈」选择工作号，录入图文。逐张检查上传后的缩略图及顺序，逐行核对正文。在日期控件失焦后回读实际日期及时间。
3. 查同账号同时间附近的已有任务。获准后提交一次，从「任务列表」重开原任务核对账号、时间、正文换行、图序、可见范围、评论及适用开关。修改使用原记录的「修改」并重新读回。
4. 原任务显示待执行时报告排期已保存。确认发布时查逐账号结果及上报时间。确认客户侧可见时用授权观察账号查具体内容及可见范围。

本技能描述图文排期、原地修改和逐账号结果核对。使用视频或分享链接前先查当前企业的字段和素材支持。
