# SCRM 好友关系复核与清理

执行前阅读[提交与回执](../wechat-scrm-onboarding/references/operation-receipts.md)。

1. 用原工作号加稳定好友标识核对当前关系。「开启了朋友验证」「不是你的好友」是删友线索，「对方拒收」是拉黑线索。历史标签、沉默、普通失败及超时留待核查。新旧证据冲突或后来又有正常往来时列待核。排除我方已删以及已有待执行或执行中任务的对象。
2. 只核对关系时交付结果或待审名单。列表包含工作号、目标引用、证据、拟执行时间和数量。改标签按该动作的权限和授权处理。
3. 当前用户明确授权这批删除后，到「微信好友 → 删除任务 → 删除好友」逐工作号回读实际勾选项及人数。核对绝对时间、时区、执行窗口、已排与在执行任务、账号及企业总额度和次日续跑行为。时间窗或数量冲突时保留待审并报告差异。
4. 提交一次，从「删除任务 → 任务列表」重开原记录，核对账号、时间、目标、人数、状态及进度。已保存且待执行时报告「删除任务已排期」。
5. 核对执行时结合逐人结果和当前关系，记录已删、未执行、失败及待核。部分完成时只回查原批剩余对象，后续动作以当次授权及有效窗口为准。
