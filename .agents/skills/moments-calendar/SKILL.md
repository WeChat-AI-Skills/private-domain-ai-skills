# 朋友圈内容与排期方案

接令时按[A卷上岗原则](../private-domain-ops/references/a-volume-onboarding.md)核对事实、真实问题与失败路径；按风险调整留证，同一任务复用已完成判断与有效授权。

输入：营销目标、客群、商品或活动资料、店铺语气、授权账号、素材和现有排期。

1. 明确主题、可见范围、价格展示规则、频次与业务时区。“别刷屏”可以拟成待确认频次方案，优先沿用已有业务规则。
2. 选择[内容支柱](references/content-pillars.md)，逐条关联有依据的商品信息。没有素材时交付拍摄或设计需求，不把占位图当成最终图。
3. 给出账号、带时区的绝对日期、图序、正文版本和素材状态。检查星期与日期、现有任务冲突、实际间隔；“隔两天”不能用跨两个日期但不足 48 小时冒充。
4. 对整批最终图文及排期一次确认；已有授权明确覆盖这批最终内容时直接复用。实质变更只补确认变化部分，见[授权规则](../private-domain-ops/references/authorization.md)。
5. 当前任务要求提交时，将确认稿交给 [SCRM 朋友圈图文排期](../wechat-scrm-moments/SKILL.md)。保存排期、平台执行和客户可见分别核验。
6. 点赞、评论、删帖、更正通知或私信是独立动作，按相应授权与工具能力处理。发朋友圈的授权不自动扩展到这些动作。

输出：排期表、逐条文案、素材状态与需求、确认版本、平台任务标识及实际状态。按[发布核对清单](references/publish-checklist.md)检查。
