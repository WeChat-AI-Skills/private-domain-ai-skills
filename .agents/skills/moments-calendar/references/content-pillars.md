# 内容支柱与文案结构

| 支柱 | 内容方向 | 所需依据 |
| --- | --- | --- |
| 新品 | 当前商品与用途 | 商品表、上新状态 |
| 搭配 | 实际搭配建议 | 可用图片和规格 |
| 场景 | 客户已确认的使用场景 | 需求资料、适用条件 |
| 口碑 | 获授权的真实反馈 | 原始依据与引用许可 |
| 幕后 | 可核实的设计或生产过程 | 实际记录 |
| 活动 | 时间、形式与报名方式 | 已批准活动规则 |

结构可用：场景 → 一个有依据的信息 → 必要证据 → 下一步。长度、语气与排期依据客户规则。

没有依据时删除具体数字、销量、客户评价、面料比例和绝对效果。不能用“昨天客户穿了一天”“退货率下降”等虚构细节填充文案。素材未完成时明确标为需求稿。
