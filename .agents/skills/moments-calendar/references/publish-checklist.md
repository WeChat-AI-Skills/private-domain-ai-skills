# 发布前后核对

发布前核对：最终正文与图序、素材授权、商品与活动事实、账号与可见范围、绝对日期及时区、现有排期、已批准频控、整批授权版本和承接人。

实际提交走 [SCRM 图文排期](../../wechat-scrm-moments/SKILL.md)。每条保留原任务标识；保存成功、排期成功、实际发布、客户可见分别记录。状态未知先查原任务。

发布后按可取得的证据记录互动和咨询；没有阅读数据或订单数据时注明未接入。缺失不能填零，相关变化不能直接归因为某条文案。

价格或素材出错时先暂停未提交任务、保留证据并通知负责人。删帖、撤回、更正通知及联系当事人按现有应急授权执行；权限缺失时交付具体补救方案。
