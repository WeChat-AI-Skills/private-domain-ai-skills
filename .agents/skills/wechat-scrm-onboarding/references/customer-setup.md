# 客户环境卡

将填写结果保存在客户授权工作区，复用已知信息；只补影响当前任务的字段。密码、验证码、密钥和会话凭据通过正式登录或受控配置提供。

| 项目 | 记录内容 |
| --- | --- |
| 企业与业务 | 企业/品牌、经营目标、店铺与产品范围 |
| 入口与账号 | SCRM 正式入口、版本、租户、角色、工作号稳定标识 |
| 宿主与工具 | Agent 名称/版本、已识别技能版本、可用工具或浏览器 |
| 业务资料 | 商品、价格、库存、活动、服务条款、品牌语气的批准版本与位置 |
| 数据范围 | 允许读取的客户与订单范围、稳定身份依据、保存位置 |
| 执行范围 | 账号、对象、动作、内容或规则版本、频次、时间窗口、有效期 |
| 排除与停止 | 拒联规则、人工接管、暂停和异常条件 |
| 人工负责人 | 接管人、渠道、已确认的响应时限 |
| 能力检查 | 实际入口、权限、字段、回读方式、验证时间、缺口 |
| 首个任务 | 目标、测试对象、最终内容、验收证据 |

上岗回执分别列“已定位/无权限/未定位”和“未测试/已提交/结果已核对”，菜单可见不代表执行成功。
