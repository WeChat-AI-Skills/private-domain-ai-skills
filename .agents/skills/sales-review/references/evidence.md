# 证据与归因

| 证据 | 可以支持 | 限制 |
| --- | --- | --- |
| 客户明确自述 | 该客户表达的偏好或原因 | 不代表其他客户，也不单独证明因果效果 |
| 逐对象执行回执 | 对应动作在记录范围内的状态 | 发出不代表阅读或购买 |
| 同口径前后数据 | 观察到的变化 | 需考虑活动、客群、渠道、季节等混淆 |
| 有设计和执行依据的对照 | 在设计适用范围内评估效果 | 仍需核对样本、分配方式、流失与不确定性 |
| 团队印象或单个案例 | 提出可检验假设 | 不能据此承诺普遍收益 |

记录时间窗口、单位、分母、去重规则、缺失覆盖和正反样本。原话按实际引用，客户私密明细保留在授权环境。

样本量和观察期按问题与风险设计；“3 例”“10 例”“两周”不自动构成可靠性或发布门槛。规则上线需要负责人授权及实际验收。
